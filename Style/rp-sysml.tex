\section{Présentation}

Ce package propose un ensemble de commande permettant le tracé de différents diagrammes SysML.

Ce package est écrit en s'appuyant sur les possibilités de tikz et s'intègre dans un  schéma réalisé avec tikz. 

\section{Installation}

Le package doit être installé dans votre répertoire personnel avec les autres packages.

\subsection{Chargement}

Placer dans l'entête de votre fichier: 
\verb!\usepackage{rp-sysml}!


\section{Use Case - Cas d'utilisation}


\subsection{Exemple générique}

On retrouve dans l'exemple ci-dessous les principales commandes permettant de tracer  un diagramme des cas d'utilisations.

\begin{tcblisting}{title={Cas d'utilisation : exemple générique},bicolor,colbacklower=white,center lower,float}
\begin{tikzpicture}
\sysmlActeur{0,0}{Utilisateur}{util}
\sysmlCase{$(util.east)+(4,-1)$}{Peser les aliments}{peser}
\sysmlCase{$(peser.east)+(2,1)$}{Tarer}{tarer}
\sysmlCase{$(peser.east)+(2.5,-1)$}{Convertir \si{\kilogram} / \si{\litre} }{conv}
\draw(util) -- (peser);
\draw(peser) -- (tarer);
\draw(peser) -- (conv);
\cadreUseCase[minimum width=15em]{Balance}{(peser) (tarer) ( conv)}
\sysmlCartouche{uc: Cas d'utilisation de la balance [Utilisation normale]}{(cadreUC) (Acteurutil)}
\end{tikzpicture}
\end{tcblisting}

\subsection{Éléments de base}



\subsubsection{Acteur}

L'usage pour la représentation d'un acteur humain est de représenter un \textbf{stickman}.

la commande  \verb!\sysmlActeur[option tikz]{pos}{texte}{nom}!  permet de dessiner un  \textbf{stickman}  à la position \textbf{pos}   avec le label \textbf{label}, l'ensemble se comporte comme alors comme un \textbf{node}  et on peut donc lui passer toutes les options de  tikz.

\begin{tcblisting}{title={Acteur: positionnement et style},sidebyside,bicolor,colbacklower=white,center lower}
\begin{tikzpicture}
\sysmlActeur{0,0}{Conducteur}{cond}
\coordinate[above right=1em of Acteurcond](a);
\sysmlActeur[red,text=blue]{a}{propriétaire}{prop}
\end{tikzpicture}
\end{tcblisting}


\subsubsection{Use case}

La commande \verb!\sysmlCase[options tikz]{pos}{Use Case}{nom}!  permet de dessiner le cas d'utilisation à la position \textbf{pos}  avec \textbf{Use Case} le texte du cas d'utilsation  avec \textbf{nom}  le nom pour désigner le cas d'utilisation.

Il est aussi possible d'utiliser directement le style prédéfini \textbf{usecase} directement dans la commande  \verb!\node[usecase]!  pour obtenir le dessin du cas d'utilisation, on a alors accès à toutes les commandes de personnalisation et de positionnement de Tikz

\begin{tcblisting}{title={Use case},sidebyside,bicolor,colbacklower=white,center lower}
\begin{tikzpicture}
\sysmlCase{0,0}{Conduire le véhicule}{cond-v}
\coordinate[below=2em of cond-v](pos);
\sysmlCase[red,text=blue,fill=green]{pos}
	{Conduire le véhicule}{cond-v}
\node[usecase] (uc3) at (0,-3) {Faire};	
\end{tikzpicture}
\end{tcblisting}


\subsubsection{Cadre frontière de l'étude et cartouche}

La commande 
\verb!\cadreUseCase[option]{titre}{liste des use case}!  permet de réaliser le cadre qui précise la frontière de l'étude. Le titre s'affiche  au dessus des cas d'utilisation. La liste des cas d'utilisation qui doivent être encadrés  doit être écrite sans séparateur.

Le nom  de ce cadre est \textbf{cadreUC}.

La commande  \verb!\sysmlCartouche{texte du cartouche}{liste des élements à encadrer}!  permet de tracer le cartouche.  On retrouve cette commande  pour tracer le cartouche et le cadre de chaque diagramme.

\begin{tcblisting}{title={Cas d'utilisation : cadre et cartouche},bicolor,colbacklower=white,center lower,breakable}
\begin{tikzpicture}
\sysmlActeur{0,0}{Utilisateur}{util}
\sysmlCase{$(util.east)+(4,-1)$}{Peser les aliments}{peser}
\sysmlCase{$(peser.east)+(2,1)$}{Tarer}{tarer}
\sysmlCase{$(peser.east)+(2.5,-1)$}{Convertir \si{\kilogram} / \si{\litre} }{conv}

\cadreUseCase[minimum width=15em,red]{Balance}{(peser) (tarer) ( conv)}
\sysmlCartouche{uc: Cas d'utilisation de la balance [Utilisation normale]}{(cadreUC) (Acteurutil)}
\end{tikzpicture}
\end{tcblisting}


\subsubsection{Relations}

On distingue deux types de relations  \textbf{extend}  et \textbf{include}, il suffit de préciser le style correspondant dans la commande de tracer \verb!\draw[extend]...!  ou   \verb!\draw[include]...!  pour obtenir le tracé correspondant.

\begin{tcblisting}{title={Relations},sidebyside,bicolor,colbacklower=white,center lower,breakable}
\begin{tikzpicture}
\node(a) at (0,0){};
\node(b) at (3,1){};
\draw[extend](a) to (b);
\node(c) at (0,-2){};
\node(d) at (3,-1){};
\draw[include](c) to (d);
\end{tikzpicture}
\end{tcblisting}


On retrouve l'utilisation sur l'exemple ci-dessous




\begin{tcblisting}{title={Exemple complet},bicolor,colbacklower=white,center lower,breakable}
\begin{tikzpicture}
\sysmlActeur{0,0}{Utilisateur}{util}
\sysmlCase{$(util.east)+(4,-1)$}{Peser les aliments}{peser}
\sysmlCase{$(peser.east)+(2,1)$}{Tarer}{tarer}
\sysmlCase{$(peser.east)+(2.5,-1)$}{Convertir \si{\kilogram} / \si{\litre} }{conv}
\draw(util) -- (peser);
\draw[include](peser) to (tarer) ;
\draw[extend]  (conv) to (peser);
\cadreUseCase[minimum width=15em]{Balance}{(peser) (tarer) ( conv)}
\sysmlCartouche{uc: Cas d'utilisation de la balance [Utilisation normale]}{(cadreUC) (Acteurutil)}
\end{tikzpicture}
\end{tcblisting}

\paragraph{États}~\par

La représentation d'un état dépend du niveau de description souhaité

\begin{itemize}
\item \verb!\sysmlStmBloc[options]{nom}{Texte}!  trace une représentation simple  d'un état. la position doit être précisée dans les option si elle n'est pas précisée, il est placé en (0,0).

\item \verb!\node[StmBloc]...! permet aussi de tracer la même représentation directement avec la commande \verb!\node!  de tikz.
\end{itemize}

\begin{tcblisting}{title={Bloc état},sidebyside, bicolor,colbacklower=white,center lower}
\begin{tikzpicture}

\node[StmBloc,fill=red!20][below right=3em of nom](nom2){Texte 2};
\end{tikzpicture}
\end{tcblisting}



Pour une description plus complète, on utilisera la commande \\
\verb!\sysmlStmBlocComplet[options]{designation}{Nom}{État}!  ou la commande  \verb!\node[StmBlocPart=xx]!  avec le style  \textbf{StmBlocPart}  qui permet de tracer  des états détaillés et aussi des états orthogonaux.  La valeur par défaut de la variable associée à  \textbf{StmBlocPart}   est 2.  

Le style des états  est défini dans le style \verb!\StmBloc!, la valeur  par défaut  est:\\

\tikzset{StmBloc/.style={draw, rounded corners=1em, minimum height=4em,
 minimum width=4em, text width=5em,align=center,fill=yellow!20}}
\end{verbatim}

\subsection{États composites}

Il est bien sur possible de tracer un  état composite avec le package  en incluant une figure tikz dans un \verb!\node!.

Pour cela, il est préférable de concevoir le schéma inclus dans une commande Latex puis l'intégrer dans l'état souhaité

Il est important de préciser la propriété \verb![remember picture]!  si on souhaite créer un lien entre l'extérieur de l'état composite et un des états à l'intérieur. Il est alors nécessaire de compiler au moins deux fois pour avoir le tracé correct.

Il faut aussi prendre en compte que Tikz  transfère les styles du node englobant aux nodes  intérieurs, il faut donc  préciser dans chaque sous schéma  les styles à appliquer  avec les commandes:

\begin{itemize}
\item commencer par remettre à 1 le nombre de sous partie du node avec  \verb!StmBlocPart=1!   dans l'environnement \textbf{tikzpicture}. on programme donc \verb!\begin{tikzpicture}[remember picture,StmBlocPart=1]!.  On précisera ensuite le nombre partie pour chaque état.
\item On précise ensuite le style que l'on veut appliquer aux différents états:
\begin{verbatim}\tikzset{StmBloc/.style={draw, rounded corners=1em, minimum height=5em, 
minimum width=4em, text width=5em,align=center,fill=red!20}} \end{verbatim}.

\end{itemize}
